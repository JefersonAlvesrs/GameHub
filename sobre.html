Um conceito de plataforma gamer criado para demonstrar desenvolvimento frontend moderno.

O PROJETO

Design imersivo. Interações reais.

O GameHub é uma vitrine fictícia com 24 jogos originais, capas vetoriais locais, navegação entre páginas, filtros combinados, ranking, coleções temáticas, favoritos e biblioteca com progresso.

O projeto funciona inteiramente no navegador, sem autenticação, backend, pagamentos ou APIs externas. Os dados de favoritos e biblioteca são mantidos com localStorage.
